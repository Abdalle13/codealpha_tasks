# CodeAlpha Internship Tasks

This repository contains the projects completed during the **CodeAlpha** internship program (October Batch).

---

## Task 1 - Social Media Platform (Veyra)

**Folder:** `Task1_SocialMediaPlatform/`

A full-stack social media platform where users can create profiles, post content, follow others, and interact with a feed.

**Stack:** React 19, Node.js, Express, Supabase, ImageKit, Netlify + Vercel

**Live:** https://veyra.netlify.app

---

## Task 2 - Project Management Tool (Taskbora)

**Folder:** `Task2_ProjectManagementTool/`

A project management app where teams can create workspaces, manage tasks with Kanban boards, and collaborate in real time.

**Stack:** React 19, Node.js, Express, Supabase PostgreSQL, Netlify + Vercel

**Live:** https://taskora-workspace.netlify.app

---

## Task 3 - Single-Vendor Fashion E-Commerce Platform (HILAARA)

**Folder:** `Task3_EcommercePlatform/`

A single-vendor luxury fashion e-commerce platform purpose-built for the Somali market. Features curated men's and women's apparel, Somali mobile money checkout (EVC Plus, eDahab, ZAAD, Pay on Delivery), nationwide logistics, dynamic cart, wishlist, and an executive administration command center.

**Stack:** React 18, Vite, Tailwind CSS, Supabase PostgreSQL, Netlify Functions, ImageKit CDN
